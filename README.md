# GBCLCD
这是一个极为廉价的、方便手工焊接的、基于RP2040的GBC高亮屏实现方案。

相比于市面上常见的高亮屏，该方案有如下优点：
1. 极为廉价！所有元器件以淘宝元器件零售价计算，总成本不超过<mark>60元</mark>，还包含邮费在内！
2. 方便手工焊接！不使用任何需要风枪和焊台才能焊接的元件。只需要一把普通的烙铁即可焊接，方便新手diy。当然，基本的焊接功底还是需要的。
3. 无需裁剪外壳！我精心选择了一款廉价的屏幕，尺寸和原装屏几乎完全一样，所以无需对外壳进行任何裁剪。
4. 即插即用，安装十分方便！调节背光只需要飞一根触摸感应的导线到外壳合适的地方即可；实时监测电池电压也只需要飞另一根电压检测的导线到电池处即可。如果两个功能都不需要，那就无需任何飞线，即插即用。

说完优点，就该说说缺点了：
1. 功能很少，只有10级调节背光亮度和实时监测电池电压这两个功能。没有OSD，没有扫描线，没有shader，其他什么都没有……
2. 屏幕显示效果不是特别优秀。毕竟不是OLED屏幕，色彩上没法和人家比。但不管怎样，比无背光的原装屏幕色彩那是好得多了。
