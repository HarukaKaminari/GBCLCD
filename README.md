# GBCLCD
这是一个极为廉价的、方便手工焊接的、基于RP2040的GBC高亮屏实现方案。

相比于市面上常见的高亮屏，该方案有如下优点：
1. 极为廉价！所有元器件以淘宝元器件零售价计算，总成本不超过<mark>60元</mark>，还包含邮费在内！
2. 方便手工焊接！不使用任何需要风枪和焊台才能焊接的元件。只需要一把普通的烙铁即可焊接，方便新手diy。当然，基本的焊接功底还是需要的。
3. 无需裁剪外壳！我精心选择了一款廉价的屏幕，尺寸和原装屏几乎完全一样，所以无需对外壳进行任何裁剪。
4. 即插即用，安装十分方便！调节背光只需要飞一根触摸感应的导线到外壳合适的地方即可；实时监测电池电压也只需要飞另一根电压检测的导线到电池处即可。如果两个功能都不需要，那就无需任何飞线，即插即用。

说完优点，就该说说缺点了：
1. 功能很少，只有10级背光亮度调节和实时监测电池电压这两个功能。没有OSD，没有扫描线，没有shader，其他什么都没有……
2. 屏幕显示效果不是特别优秀。毕竟不是OLED屏幕，色彩上没法和人家比。但不管怎样，比无背光的原装屏幕色彩那是好得多了。
3. 可视区域比较小，和原装屏差不多，不像别人家的大屏，比原装屏大一圈。

# 工作原理
简单来说，就是RP2040通过PIO硬件，实时采集GBC的LCD总线数据。
1. PIO硬件监测VSync信号，一旦采集到VSync，立刻初始化LCD，同时启动捕获流程，在每个CLK信号到来的时候，采集R1-R5、G1-G5和B1-B5数据，并保存到缓冲区。这一流程一直持续到采集到HSync信号的时候才停止。
2. 一旦采集了一整条扫描线的数据，立刻启动DMA将其直接发送到LCD。与此同时，切换缓冲区，准备下一条扫描线的采集。
3. 一旦采集到了下一条扫描线的数据，同样立刻启动DMA将其发送到LCD。同时切换缓冲区，准备再下一条扫描线的采集。这一流程一直持续到采集到VSync信号，即整个屏幕都采集完才停止。
4. 如此循环永不停歇。

TTP223触摸开关检测触摸信号；STC8G1K08A单片机响应触摸信号和控制PWM硬件，驱动LCD的背光。
1. 单片机初始化PWM硬件，输出PWM信号控制LCD背光亮度。
2. 单片机立刻进入睡眠模式。
3. 一旦TTP223检测到了触摸，就输出一个信号给到单片机，将其唤醒。
4. 单片机输出下一级PWM信号，驱动LCD的背光。完成之后再度睡眠。
5. 如此循环永不停歇。

## 为何不使用RP2040输出PWM驱动LCD的背光？为何不使用RP2040实现触摸检测？
因为GPIO不够用了……RP2040 Tiny开发板只对外引出了20个GPIO，再加上2个用于跳线的GPIO，一共22个。而采集GBC的LCD总线数据，需要15个RGB+VSync+HSync+CLK=18个GPIO；SPI接口的LCD至少需要SCK+SDA+DC=3个GPIO；检测电池电压又需要1个ADC Input，正好将所有GPIO全部用光，再也拿不出任何多余的GPIO来驱动LCD背光和检测触摸了。

# 还有优化余地吗？
有哇！你可以考虑把PCB换成柔性电路板（即fpc），去掉RP2040 Tiny模块，直接在fpc上面贴RP2040芯片和外围电路。这样就能省去FPC排线和它的插座。不再受限于Tiny模块较少的GPIO，这样就可以用RP2040直接检测触摸和输出PWM驱动LCD背光，于是又可以省去STC8G1K08A单片机、TTP223触摸开关和它们的外围电路。三片74LVC245也可以直接用1K的排阻代替，也能节省一些成本。

但是，嘉立创白嫖fpc需要门槛，直接用烙铁焊接RP2040芯片也是个相当困难的挑战。这个方案相对来说不适合新手diy。
